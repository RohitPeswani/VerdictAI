## 📱 Overview

The VerdictAI mobile app is the **Card Member facing interface** of the VerdictAI Frictionless Dispute Resolution Platform. It allows cardholders to:

1. **File disputes** against settled card transactions in a guided 4-step wizard
2. **Track case progress** in real time against the backend 6-state FSM (48h SLA countdown)
3. **View AI resolution rationale** generated by the Gemini XAI reasoning layer
4. **Receive push notifications** for all lifecycle status transitions

## 🚀 Running the App

### Prerequisites
- Node.js (v18+) and npm
- Expo Go app installed on your phone (free from Play Store / App Store)

### Steps

```bash
# 1. Navigate into the mobile app directory
cd VerdictAI/mobile-app

# 2. Install all dependencies (first time only)
npm install

# 3. Start the Expo development server
npx expo start
```

After running Step 3:
- **On your phone:** Scan the QR code in Expo Go
- **In browser:** Press `w` to open web preview
- **Android emulator:** Press `a` (requires Android Studio)

## 🔌 API Integration

All screens connect to **Darshan Prajapati's FastAPI backend** (`backend/app/api/v1/`):

| Screen | Endpoint | Method |
|:---|:---|:---|
| Dispute Filing Wizard (Step 1) | `/api/v1/transactions/cardholder/{id}` | `GET` |
| Dispute Filing Wizard (Step 4) | `/api/v1/disputes` | `POST` |
| Evidence Upload (Step 3) | `/api/v1/evidence/upload` | `POST` |
| My Disputes Home | `/api/v1/disputes?cardholder_id={id}` | `GET` |
| Dispute Detail / SLA Tracker | `/api/v1/disputes/{dispute_id}` | `GET` |

To connect to a live backend, update `src/services/apiClient.ts`:
```ts
const BASE_URL = 'http://<your-backend-ip>:8000/api/v1';
```
