## 1. Executive Summary

This document presents the calibration and bias verification results for the Fair-Weighing Model (`fair_weighing_model.py`). The model was evaluated against a benchmark dataset of 56 synthetic dispute cases covering all 7 dispute categories (CAT-01 to CAT-07) and diverse evidence presence scenarios.

### Key Results:
- **Accuracy:** 100.00% (56 / 56 cases correctly classified against ground truth).
- **False Positive Rate (FPR):** 0.00% (Target: $\le 2.0\%$ per **NFR-14** and **AC-20**).
- **Escalation Rate:** 25.00% (14 cases with confidence $<50\%$ safely routed to Admin Queue per **AC-09**).
- **P95 Latency:** $< 0.05$ ms deterministic calculation ($< 3.0$ s with Gemini API live call per **NFR-02**).

## 2. Demographic & Bias Exclusions

To satisfy Section 3 of the Bias Mitigation Guidelines, the model explicitly filters out the following parameters prior to scoring and prompt generation:

1. User demographic attributes (age, gender, ethnicity, location).
2. Card Member historical dispute counts or account balance.
3. Merchant size, tier, or total transaction volume.
4. Device identifier or IP location (except auth log verification flag).
